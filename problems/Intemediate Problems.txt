Problem Statement:

type.

- If count is 2 and either is decimal → call `add(double, double)`

Concepts Covered:
- Method Overloading
- Polymorphism
- Return Types
- Type Casting

add(2: 10,20)  /  add(3: 5,10,15)  /  add(2: 2.2,3.3)
Expected Output:
30  /  30  /  5.5

based on argument count and types.

Test Cases
#	Input	                    Expected Output

3   count = 2 add(2.2, 3.3)           5.5
