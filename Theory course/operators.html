Operators

An operator is a symbol that tells Java to perform an action on one or more values (called operands). The result of that action is usually a new value.

Operators are grouped by the kind of work they do. Learning the groups helps you choose the right operator and avoid logic mistakes.

Types of Operators (Overview)

Arithmetic: math on numbers like +, -, *, /, %.

Assignment: store or update values like =, +=, -=, *=, /=, %=.

Relational: compare values and return true/false like ==, !=, >, <, >=, <=.

Logical: combine boolean results like &&, ||, !.

Increment/Decrement: add or subtract 1 using ++ and --.

Unary: work on a single operand, like +x, -x, !x, and ++x.

Ternary: a short if‑else using ?:.

Bitwise: operate on bits in integers like &, |, ^, ~.

Shift: move bits left or right using <<, >>, >>>.

Type check: instanceof checks whether an object is of a given type.

Arithmetic operators

Arithmetic operators perform basic math: +, -, *, /, % (modulus).

+ adds, - subtracts, * multiplies, / divides, and % gives the remainder.

When both numbers are integers, division drops the decimal part: 10 / 3 becomes 3.

If any number is decimal (double), the result keeps decimals: 10.0 / 3 gives 3.333...

Modulus is useful for checking even/odd or repeating patterns, like every 5th item.

int a = 10; int b = 3; System.out.println(a + b); System.out.println(a / b); System.out.println(a % b);
Exam Point: What is the remainder of 10 % 3?

Assignment operators

Assignment operators store values in variables. Short forms combine operation and assignment.

= assigns a value, while +=, -=, *=, /=, and %= update the same variable.

Example: x += 3 is the same as x = x + 3.

Assignment happens right to left: in a = b = 5, both a and b become 5.

int x = 5; x += 3; x *= 2;
Exam Point: Expand x += 3 into its full form.

Relational operators

Relational operators compare two values and return true or false.

They include == (equal), != (not equal), >, <, >=, and <=.

Use them for numeric comparisons like scores, ages, or limits.

For objects like String, use equals() to compare content, not ==.

int a = 7; int b = 10; System.out.println(a < b); System.out.println(a == b);
Exam Point: List all relational operators in Java.

Logical operators

Logical operators combine conditions: && (AND), || (OR), ! (NOT).

&& is true only when both sides are true. || is true if at least one side is true.

! flips the result, so !true becomes false and !false becomes true.

Java uses short‑circuit evaluation: in (A && B), if A is false, B is not checked.

Use parentheses to make complex conditions easier to read and avoid mistakes.

boolean pass = true; boolean attendance = false; System.out.println(pass && attendance); System.out.println(pass || attendance);
Exam Point: When does AND return true?

Increment & Decrement

Increment ++ adds 1 and decrement -- subtracts 1. They can be prefix or postfix.

Prefix (++n) changes the value first, then uses it in the expression.

Postfix (n++) uses the current value first, then updates it.

When used alone in a line, both prefix and postfix give the same final value.

int n = 5; System.out.println(++n); System.out.println(n--);
Exam Point: Differentiate prefix and postfix with output.

Unary operators

Unary operators work with a single operand. They change the value or its meaning without needing a second value.

+ keeps the value as positive, - changes the sign, ! flips boolean, and ++/-- change numbers by 1.

int num = 7; System.out.println(-num); boolean isOpen = false; System.out.println(!isOpen);
Exam Point: Write one example each for unary +, unary -, and !.

Ternary operator

The ternary operator is a short form of if‑else that returns a value.

Syntax: condition ? valueIfTrue : valueIfFalse

It is best for simple decisions, like choosing a label or message.

int age = 20; String result = (age >= 18) ? "Adult" : "Minor"; System.out.println(result);
Exam Point: Convert an if‑else into a ternary expression.

Bitwise operators

Bitwise operators work on the binary form of integers. They compare or change each bit.

& (AND), | (OR), ^ (XOR), and ~ (NOT) are used for low‑level operations.

Bitwise operators are common in masking, flags, and performance‑critical code.

int a = 5; int b = 3; System.out.println(a & b); System.out.println(a | b); System.out.println(a ^ b); System.out.println(~a);
Exam Point: What does XOR return when bits are different?

Shift operators

Shift operators move bits left or right, which is similar to multiplying or dividing by powers of 2.

<< shifts left, >> shifts right with sign, and >>> shifts right with zero fill.

Example: 5 << 1 gives 10, because bits move one place left.

int x = 5; System.out.println(x << 1); System.out.println(x >> 1); System.out.println(x >>> 1);
Exam Point: Why is right shift different for negative numbers?

instanceof operator

instanceof checks whether an object belongs to a class or interface type.

It returns true if the object can be safely treated as that type.

String name = "Asha"; System.out.println(name instanceof String);
Exam Point: When does instanceof return false?
