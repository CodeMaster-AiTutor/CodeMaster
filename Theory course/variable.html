Variables

What is a Variable

A variable is a named memory location used to store data while a program runs. The value can change during execution, which makes programs flexible.

Every variable has a data type (what kind of value it stores) and a name (how we refer to it).

Think of a variable as a labeled box: the label is the name, and the box type decides what can be stored inside.

Variables make programs readable because you can refer to data with meaningful names instead of hard-coded values.

int age = 18; String name = "Asha";
Exam Point: Define variable and write one declaration with initialization.

int

int stores whole numbers without decimals. It is used for counting, indexing, and simple calculations.

Examples include age, number of students, or array positions.

int cannot hold fractional values, so 3.5 is invalid for int.

int students = 45; int year = 2026; int temperature = -5;
Exam Point: Write two valid int values and one invalid value.

double

double stores decimal numbers. It is used for measurements, percentages, and precise calculations.

It can represent fractional values like 3.14 or 99.99, which int cannot.

Use double when you need decimals such as marks, temperature, or money calculations.

double height = 5.9; double pi = 3.14159; double percent = 87.5;
Exam Point: Why is double preferred over float in Java?

boolean

boolean stores only two values: true or false. It is used in conditions and decision making.

Any comparison like age >= 18 produces a boolean.

Boolean values control if-else statements and loops.

boolean isStudent = true; boolean hasTicket = false;
Exam Point: Give one real-life example where boolean is used.

char

char stores a single character and is written in single quotes. Java uses Unicode, so it can store letters, digits, and symbols.

A char holds exactly one character, not a word or sentence.

Because of Unicode, it can store characters from many languages.

char grade = 'A'; char symbol = ';
Exam Point: Why is 'AB' invalid for char?

String

String stores text. Strings are written inside double quotes and can be combined using +.

Strings can contain multiple characters and spaces.

String is a class in Java, not a primitive type, so it has many useful methods.

String city = "Delhi"; String message = "Welcome"; String full = message + " " + city;
Exam Point: Write a String that joins your name and city.

Static Typing

Java is statically typed, which means the type of a variable is checked at compile time and cannot change later.

This prevents many errors before the program even runs.

If you declare a variable as int, it can never store text or decimals.

int score = 90; score = 95;
Exam Point: What error occurs if you assign text to an int?

Naming Rules

Variable names must be meaningful and follow rules: no spaces, cannot start with a number, and cannot use Java keywords.

Use camelCase for readability, like studentAge or totalMarks.

Good names make code easier to understand and maintain.

int studentAge = 20; String firstName = "Riya";
  • Valid: totalMarks, _count, $price
  • Invalid: 1age, my name, class
Exam Point: Write three valid and two invalid variable names.
