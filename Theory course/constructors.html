Constructors

What is a Constructor?

A constructor is a special block of code that initializes a newly created object. It runs automatically when you use the new keyword. Its primary purpose is to set initial values for object attributes so the object is ready to use immediately. Think of it as a setup routine that prepares the object's internal state before you call any methods.

Student s = new Student();

At the moment you use new, the constructor runs and sets up the object.

Constructor Rules

Constructors follow strict rules that distinguish them from regular methods. They must have the exact same name as the class and cannot have a return type, not even void. If you violate these rules, the compiler treats them as normal methods, which can lead to confusing bugs.

  • Same name as the class
  • No return type (not even void)
  • Called automatically when you use new

Default constructor

If you do not write any constructor in your class, Java creates one for you automatically. This "default constructor" takes no arguments and initializes all fields to their default values (null, 0, false). It ensures that you can always create an object even if you haven't defined how initialization should happen. However, once you add your own constructor, this automatic one disappears.

public class Student { String name; int age; // Java adds this invisibly: // public Student() { } }

Default values are: null for objects, 0 for numbers, and false for booleans.

Exam Point: When does Java generate a default constructor?

Parameterized constructor

A parameterized constructor allows you to pass specific values when creating an object. This is essential for setting unique properties for each instance, like a student's name or ID. By enforcing these parameters, you ensure that no object is created in an invalid or empty state. It replaces the need to call multiple setter methods right after creation.

public class Student { String name; int age; double marks; public Student(String name, int age, double marks) { this.name = name; this.age = age; this.marks = marks; } @Override public String toString() { return name + " | Age: " + age + " | Marks: " + marks; } } Student s1 = new Student("Alice", 20, 92.5); Student s2 = new Student("Bob", 22, 78.0); System.out.println(s1); System.out.println(s2);

All fields are set in one clean line without extra assignments later.

Exam Point: How is a parameterized constructor called?

this keyword

The this keyword is a reference to the current object inside a method or constructor. It is commonly used to distinguish between class fields and parameters with the same name. Without this, the parameter shadows the field, meaning the assignment would have no effect on the object's state. Using this makes your code clear and prevents variable shadowing errors.

public Student(String name, int age) { this.name = name; this.age = age; }

If you skip this when names match, you only assign the parameter to itself.

public Student(String name, int age) { name = name; age = age; }
Exam Point: What is the meaning of this.name?

Constructor Overloading

Constructor overloading allows a class to have multiple constructors with different parameter lists. This gives flexibility to the user of your class, letting them create objects in different ways depending on the data available. For example, one constructor might take all details, while another sets default values for missing information. Java selects the correct constructor based on the number and type of arguments passed.

public class Student { String name; int age; double marks; String grade; public Student(String name, int age, double marks) { this.name = name; this.age = age; this.marks = marks; this.grade = marks >= 60 ? "Pass" : "Fail"; } public Student(String name, int age) { this.name = name; this.age = age; this.marks = 0; this.grade = "Not Graded"; } public Student(String name) { this.name = name; this.age = 0; this.marks = 0; this.grade = "Not Graded"; } }
Exam Point: What is constructor overloading?

this() — Constructor Chaining

Constructor chaining allows one constructor to call another within the same class using this(). This reuses code and avoids duplication when you have multiple overloaded constructors. The call to this() must be the very first statement in the constructor body. By centralizing initialization logic in one main constructor, you make your class easier to maintain.

public class Student { String name; int age; double marks; public Student(String name, int age, double marks) { this.name = name; this.age = age; this.marks = marks; } public Student(String name, int age) { this(name, age, 0.0); } public Student(String name) { this(name, 18, 0.0); } }
Exam Point: Why must this() be the first line?

Copy Constructor

A copy constructor creates a new object by copying the attributes of an existing object. This is useful when you need a duplicate that is independent of the original. Unlike a simple reference assignment, which points two variables to the same object, a copy constructor ensures deep or shallow copying of values. It is often used to pass objects safely without modifying the original.

public class Student { String name; int age; double marks; public Student(String name, int age, double marks) { this.name = name; this.age = age; this.marks = marks; } public Student(Student other) { this.name = other.name; this.age = other.age; this.marks = other.marks; } }
Exam Point: What is the purpose of a copy constructor?

Constructor vs Method

While both contain code blocks, constructors and methods serve different purposes. Constructors initialize objects and have no return type, whereas methods define object behavior and must declare a return type. Understanding this distinction is key to mastering Java's object-oriented structure.

Feature Constructor Method
Name Same as class Any name
Return type None Must have one
Called Automatically with new Manually
Purpose Initialize object Perform operations
this() Can call another constructor Cannot

What Happens When No Constructor is Written?

If you don't write any constructor, Java inserts a default no-argument constructor for you. However, as soon as you define even one parameterized constructor, this automatic default constructor is removed. This means you cannot create an empty object unless you explicitly define a no-argument constructor yourself. This rule enforces strict initialization if that's what your design requires.

public class Car { String brand; public Car(String brand) { this.brand = brand; } } Car c = new Car(); Car d = new Car("Toyota");

If you still want a no‑arg constructor, you must write it yourself.

Full Example: Product Class

This comprehensive example demonstrates overloading, chaining, and encapsulation in a single class. It shows how to handle optional parameters by providing multiple constructors that delegate to a main one. The toString method allows easy verification of the object's state. This pattern is very common in real-world Java applications.

public class Product { private int id; private String name; private double price; private int stock; public Product(int id, String name, double price, int stock) { this.id = id; this.name = name; this.price = price; this.stock = stock; } public Product(int id, String name) { this(id, name, 0.0, 0); } public Product(Product other) { this(other.id, other.name, other.price, other.stock); } public void restock(int qty) { stock += qty; } public boolean sell(int qty) { if (stock < qty) { System.out.println("Not enough stock."); return false; } stock -= qty; return true; } @Override public String toString() { return String.format("%-5d %-15s $%-8.2f Stock: %d", id, name, price, stock); } }

Common Mistakes

Beginners often accidental declare a return type for a constructor, turning it into a method. Another common issue is calling this() later in the body instead of the first line. Forgetting to define a no-arg constructor when one is needed by frameworks is also a frequent trap. The examples below highlight these errors so you can avoid them.

public void Student(String name) { } public Student(String name) { } public Student(String name) { System.out.println("hello"); this(name, 18); } public Student(String name, int age) { } Student s = new Student();
Exam Point: Identify the mistake in each example.

Try to write the code from scratch without looking at the examples first. Verify your results by printing the object details to the console.

  • Create a Rectangle class with width and height, and an area() method set by constructor.
  • Create a Person with name and email. Use this properly in the constructor.
  • Create a Product class with overloaded constructors and refactor using this() chaining.
  • Create a BankAccount class with a copy constructor and verify copy independence.
  • Create a Movie class with full, partial, and copy constructors.
  • Write a Circle class with radius default 1 and methods area() and perimeter().
