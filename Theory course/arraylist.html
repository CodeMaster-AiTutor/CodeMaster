ArrayList

What is ArrayList?

ArrayList is a resizable array implementation of the List interface. Unlike standard arrays, which have a fixed length, ArrayList grows automatically when you add more elements. It allows you to store duplicates and maintains the insertion order of elements. Under the hood, it uses a standard array that gets replaced by a larger one when it fills up. This makes it the go-to choice for lists where you don't know the exact number of elements in advance.

import java.util.*; ArrayList names = new ArrayList<>(); // default capacity ArrayList nums = new ArrayList<>(16); // with initial capacity
Exam Point: ArrayList maintains insertion order and allows duplicates.

Size vs Capacity

The size() method tells you how many elements are currently in the list, while capacity is the length of the internal backing array. When the size reaches the capacity, ArrayList creates a new, larger array and copies everything over. This resizing operation is costly, so it's good practice to set an initial capacity if you know the approximate size. You can also use trimToSize() to free up unused memory after filling the list.

System.out.println(names.size()); names.ensureCapacity(100); // reduce future resizes names.trimToSize(); // shrink to current size

Core Operations

ArrayList provides simple methods to manipulate data. add() appends elements to the end, while get() gives you instant access to any element by its index. set() updates an element at a specific position, and remove() deletes elements by index or value. Be careful when removing by value with integers, as the compiler might confuse the number for an index. These operations cover 90% of what you do with lists.

ArrayList list = new ArrayList<>(); list.add(10); // append list.add(0, 5); // insert at index int first = list.get(0); // read list.set(0, 7); // replace at index list.remove(1); // remove by index list.remove(Integer.valueOf(7)); // remove by value boolean has10 = list.contains(10); int pos = list.indexOf(10); list.clear(); // remove all
Exam Point: remove(int) removes by index; remove(Object) removes by value.

Iteration Patterns

You can loop through an ArrayList in several ways depending on your needs. The enhanced for-loop is the cleanest for reading elements. A standard for-loop gives you access to the index, which is useful if you need to know the position. Iterators are the safest way to remove elements while looping, as they prevent ConcurrentModificationException. ListIterator even allows you to traverse backwards.

// for-each for (String n : names) { System.out.println(n); } // index-based for (int i = 0; i < names.size(); i++) { System.out.println(i + ": " + names.get(i)); } // Iterator (supports safe removal during traversal) Iterator it = names.iterator(); while (it.hasNext()) { String v = it.next(); if (v.startsWith("A")) it.remove(); } // ListIterator (bidirectional) ListIterator li = names.listIterator(names.size()); while (li.hasPrevious()) { System.out.println(li.previous()); }
Exam Point: Iterators are fail‑fast if list is structurally modified outside the iterator.

Bulk and Predicate Operations

Java provides powerful methods to handle multiple elements at once. addAll() merges another collection into your list, which is faster than adding items one by one. removeIf() accepts a lambda condition to delete all matching elements in a single pass. These methods are optimized and result in cleaner, more readable code. They are essential for filtering data efficiently.

names.addAll(Arrays.asList("Asha", "Riya", "Karan")); names.removeIf(s -> s.length() < 4); // Java 8+

Sorting

Sorting organizes your list in a specific order, such as alphabetical or numerical. Collections.sort() uses the natural order of elements (like A to Z). For custom sorting, you can pass a Comparator to define your own rules, such as sorting by string length. The sort algorithm is stable and efficient (O(n log n)). Always sort before searching if you plan to use binary search.

Collections.sort(names); // natural order names.sort(Comparator.comparingInt(String::length)); // by length
Exam Point: Collections.sort(list) uses natural ordering; provide Comparator for custom order.

Conversion

Sometimes you need to convert between an ArrayList and a standard array. toArray() returns a static array containing all list elements. Conversely, Arrays.asList() wraps an array into a fixed-size list. To get a fully modifiable ArrayList from an array, pass the wrapper to the ArrayList constructor. This is a common pattern when bridging legacy APIs with modern collections.

// to array String[] arr = names.toArray(new String[0]); // from array (fixed-size list!) List l = Arrays.asList("a", "b", "c"); ArrayList copy = new ArrayList<>(l); // real, resizable copy

Performance (Big-O)

Understanding performance helps you choose the right collection. ArrayList is excellent for reading data but slower for inserting in the middle.

Operation Time Complexity Description
get(i) O(1) Instant access by index
add(e) O(1) amortized Fast append (occasional resize)
add(i, e) O(n) Slow insert (shifts elements)
remove(i) O(n) Slow remove (shifts elements)
contains(e) O(n) Linear search
Exam Point: Prefer ArrayList for reads and appends; prefer LinkedList for frequent middle inserts/removes.

Streams & Filtering

The Stream API allows you to process lists functionally. You can filter, map, and sort elements without modifying the original list. This approach is declarative, meaning you describe what you want rather than how to loop. It is very powerful for data transformation pipelines. The result can be collected back into a new List.

List result = names.stream() .filter(s -> s.startsWith("R")) .sorted() .toList(); // Java 16+

Thread-Safety

By default, ArrayList is not thread-safe, meaning it can break if modified by multiple threads simultaneously. If you need concurrent access, wrap it with Collections.synchronizedList(). Alternatively, use CopyOnWriteArrayList for thread-safe iteration. Ignoring thread safety in multi-threaded apps is a common source of bugs. Always synchronize access when sharing lists.

List sync = Collections.synchronizedList(new ArrayList<>());
