Methods

Why methods

Methods group reusable steps into one place. They remove repetition, make programs readable, and support testing.

// Without methods (repetition) System.out.println("Welcome, Asha"); System.out.println("Welcome, Ravi"); // With a method static void greet(String name) { System.out.println("Welcome, " + name); } // greet("Asha"); greet("Ravi");
Exam Point: Name two reasons to use methods.

Method syntax & parts

Format: modifiers returnType name(parameters) { body }

static int add(int a, int b) { int sum = a + b; // local variable return sum; }

Static vs instance methods

static methods belong to the class and can be called from main directly. Instance methods need an object.

class Box { int length = 3, width = 4; int area() { return length * width; } // instance static int doubleOf(int x) { return 2 * x; } // static } Box b = new Box(); System.out.println(b.area()); System.out.println(Box.doubleOf(5));
Exam Point: Why can't main call a non‑static method without an object?

Parameters

Parameters are inputs; arguments are actual values passed during the call.

static void showSum(int a, int b) { System.out.println(a + b); } // showSum(5, 7);

Return values

Use return to send a single value back to the caller. The value must match the declared type.

static boolean isEven(int n) { return n % 2 == 0; }
Exam Point: Can a void method use return? Yes, but without a value, to exit early.

Method overloading

Same method name, different parameter number, type, or order. Return type alone does not overload.

static int max(int a, int b) { return (a > b) ? a : b; } static double max(double a, double b) { return (a > b) ? a : b; }
Exam Point: Why can't overloading differ only by return type?

Pass‑by‑value (important)

Java passes copies of values. Changing a parameter does not change the original primitive variable.

static void addOne(int x) { x = x + 1; } int a = 5; addOne(a); System.out.println(a); // still 5

Scope & lifetime

Parameters and local variables exist only inside the method block.

static void demo() { int temp = 10; // local System.out.println(temp); } // System.out.println(temp); // error: out of scope

Recursion (basics)

A method calling itself with a smaller subproblem. Requires a base case.

static int fact(int n) { if (n == 0) return 1; // base return n * fact(n - 1); // recursive step }

Common mistakes

  • Calling non‑static methods from main without creating an object.
  • Missing return in non‑void methods.
  • Assuming Java is pass‑by‑reference for primitives.
