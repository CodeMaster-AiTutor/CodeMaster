Loops

Why Loops Exist

Programs often need to repeat work: print numbers, read multiple inputs, count totals. Writing the same statement 100 times is not practical. Loops repeat a block until a condition changes.

  • ATM tries up to 3 PIN attempts
  • Sum marks of N subjects
  • Process each element in a list

Loop Anatomy

Every loop depends on three parts: initialization, condition, update. Missing update often causes infinite loops.

int i = 1; // initialization while (i <= 3) { // condition System.out.println(i); i++; // update }

while loop

Concept

Checks the condition before each iteration. Runs zero or more times.

Syntax

while (condition) { // statements }

Examples

// Print 1..5 int i = 1; while (i <= 5) { System.out.println(i); i++; } // Sum of first N numbers int n = 5, sum = 0, k = 1; while (k <= n) { sum += k; k++; } System.out.println(sum);
Exam Point: Forgetting the update creates an infinite loop.

do-while loop

Executes the body at least once; condition is checked after the body.

int choice; do { // show menu System.out.println("1.Play 2.Exit"); choice = 2; // imagine user input } while (choice != 2);
Exam Point: do-while guarantees one execution.

for loop

Best when you know how many times to repeat. Three parts: init; condition; update.

for (int i = 1; i <= 5; i++) { System.out.println(i); } // Multiple variables for (int a = 1, b = 5; a <= b; a++, b--) { System.out.println(a + "," + b); } // Empty parts are allowed int x = 1; for (; x <= 3; ) { // behaves like while System.out.println(x); x++; }
Exam Point: for(;;) is an infinite loop.

Enhanced for-each

Reads elements of arrays/collections without using indexes. Use when you only need to access, not modify the index.

int[] arr = {2, 4, 6}; for (int val : arr) { System.out.println(val); }

Nested loops

Loop inside another loop, often used for tables and patterns. Total iterations = outer × inner counts.

// 3x3 multiplication table for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 3; j++) { System.out.print((i*j) + " "); } System.out.println(); }
Exam Point: If outer runs 3 times and inner 4 times → 12 total iterations.

break & continue

break exits the loop immediately. continue skips the current iteration and jumps to the next check.

// Print 1..5 except 3; stop at 4 for (int i = 1; i <= 5; i++) { if (i == 3) continue; if (i == 5) break; System.out.println(i); }
Exam Point: Order of checks matters for break/continue.

Choosing the right loop

  • Unknown count → while
  • At least once → do-while
  • Known count or index → for
  • Read-only over arrays/collections → for-each

Common mistakes

  • Off-by-one errors (use <= vs < carefully)
  • Changing the loop variable inside nested blocks
  • Missing braces causing only the next statement to loop
