Conditionals

Why Conditionals Exist

A computer is extremely fast and extremely literal. If you never tell it when to do something, it will try to do everything. Programs must be able to choose different paths depending on situations. That ability is called control flow.

Conditionals are the decision-making part of control flow. They decide which block of code should run and which should be skipped.

Without conditionals, every program would follow one fixed path, making it useless for real-world problems.

  • Imagine an ATM without conditions: Enter wrong PIN → money still comes out. Disaster.
  • Conditionals allow a program to ask: Is this situation true? If yes → do something; if no → do something else.

Boolean Logic (The Brain Behind Conditionals)

Every decision becomes a boolean value: true or false. Computers never think “maybe”.

Relational operators (<, >, ==, !=, <=, >=) produce boolean results.

Logical operators (&&, ||, !) combine boolean values to build complex conditions.

5 > 3 // true 5 < 3 // false int age = 18; age >= 18 // true or false

Conditionals always depend on expressions that return boolean.

if statement

Concept

The if statement runs code only when the condition is true.

If the condition is false, Java skips the block completely and continues to the next line.

Use a single if for one decision without an alternate path.

Syntax

if (condition) { // statements }

Execution Flow

  • Evaluate condition
  • If true → block executes
  • If false → block is skipped

Example 1

int age = 20; if (age >= 18) { System.out.println("You can vote"); } // Output: You can vote

Example 2

int age = 15; if (age >= 18) { System.out.println("You can vote"); } // Output: (no output) because condition is false

Important Rule

The parentheses must contain a boolean expression.

// Wrong // if (5) // error // Correct if (5 > 2) { }
Exam Point: Java is strict; conditions must evaluate to boolean.

if – else

Concept

If the condition is false, we need an alternative path.

This guarantees exactly one block runs, either the true block or the false block.

Use if‑else when there are only two outcomes.

Syntax

if (condition) { // true block } else { // false block }

Example

int marks = 40; if (marks >= 40) { System.out.println("Pass"); } else { System.out.println("Fail"); }

if – else if – else Ladder

Used when multiple possibilities exist. Java checks top-to-bottom and stops at the first true condition.

Only one block runs in a ladder, even if multiple conditions are true.

Put the most specific or highest-value conditions first to avoid incorrect matches.

int marks = 82; if (marks >= 90) { System.out.println("Grade A"); } else if (marks >= 75) { System.out.println("Grade B"); } else if (marks >= 60) { System.out.println("Grade C"); } else if (marks >= 40) { System.out.println("Grade D"); } else { System.out.println("Fail"); } // Output: Grade B (because 82 >= 75)

Important Observation

Order matters. Wrong ordering can make later conditions unreachable.

// Wrong if (marks >= 40) { System.out.println("Pass"); } else if (marks >= 90) { System.out.println("Grade A"); } // "Grade A" will never execute because 90 is already >= 40

Nested if

Decision inside another decision. Use when the second test only matters after the first is true.

This mirrors real logic: you check step 1, then check step 2 only if step 1 passes.

Nested if makes the flow explicit and easier to debug for beginners.

String username = "admin"; String password = "1234"; if (username.equals("admin")) { if (password.equals("1234")) { System.out.println("Login successful"); } else { System.out.println("Wrong password"); } } else { System.out.println("User not found"); }

You can also combine conditions:

if (username.equals("admin") && password.equals("1234")) { System.out.println("Login successful"); }
Tip: Nested if may be clearer for beginners and debugging.

switch statement

Why switch Exists

If you have many else-if checks for one variable, switch is cleaner and faster to read.

It is best when you compare one value against fixed constants such as menu choices or days of the week.

Switch compares one expression and jumps directly to the matching case.

Syntax

switch (variable) { case value1: // statements break; case value2: // statements break; default: // statements }

Example: Menu System

int choice = 2; switch (choice) { case 1: System.out.println("Deposit"); break; case 2: System.out.println("Withdraw"); break; case 3: System.out.println("Balance"); break; default: System.out.println("Invalid option"); } // Output: Withdraw

The break Statement (Extremely Important)

Without break, Java continues executing next cases (fall-through).

Fall-through can be useful in rare cases but usually causes bugs when you forget break.

Use break to stop execution at the end of a matched case.

int day = 1; switch (day) { case 1: System.out.println("Monday"); case 2: System.out.println("Tuesday"); case 3: System.out.println("Wednesday"); } // Output: // Monday // Tuesday // Wednesday

default runs when no case matches (like else).

When to Use What

Choose the structure that matches the type of decision you need to make.

  • Two outcomes → if-else
  • Range checking → if – else if – else
  • Nested decisions → nested if
  • Fixed menu choices → switch

Real Life Decision Examples

ATM Withdrawal:

This is a layered decision, so nested if is a natural fit.

  • Card valid?
  • PIN correct?
  • Balance sufficient?

Multiple layered decisions → use nested if or combine with logical operators.

Exam Point: Write a condition for “age >= 18 and has ID”.
