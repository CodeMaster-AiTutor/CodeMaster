File Handling

What is File Handling?

File handling lets your Java program read from and write to files on disk.

Data saved in files persists even after the program closes.

Use Case Example
Save user data Profiles, settings, logs
Read configurations App config files
Export reports .txt or .csv outputs

Key Classes

Class Purpose
FileWriter Write characters to a file
BufferedWriter Efficient writing (buffered)
FileReader Read characters from a file
BufferedReader Efficient reading line by line
File Represents a file or directory
PrintWriter Write formatted text

Writing to a File — FileWriter

import java.io.*; public class WriteFile { public static void main(String[] args) { try (FileWriter fw = new FileWriter("output.txt")) { fw.write("Hello, World!\n"); fw.write("This is line 2.\n"); fw.write("Java File Handling.\n"); System.out.println("File written successfully."); } catch (IOException e) { System.out.println("Error: " + e.getMessage()); } } }

By default FileWriter overwrites the file. To append, pass true as the second argument.

new FileWriter("output.txt", true)

Writing with BufferedWriter — Faster

try (BufferedWriter bw = new BufferedWriter( new FileWriter("students.txt"))) { bw.write("ID,Name,Age,Marks"); bw.newLine(); bw.write("1,Alice,20,92.5"); bw.newLine(); bw.write("2,Bob,22,78.0"); bw.newLine(); bw.write("3,Charlie,21,65.5"); bw.newLine(); System.out.println("Written successfully."); } catch (IOException e) { e.printStackTrace(); }

bw.newLine() uses the correct line break for the platform.

Writing with PrintWriter — Formatted Output

try (PrintWriter pw = new PrintWriter( new FileWriter("report.txt"))) { pw.println("=== Student Report ==="); pw.printf("%-5s %-15s %-6s%n", "ID", "Name", "Marks"); pw.println("-".repeat(30)); pw.printf("%-5d %-15s %-6.1f%n", 1, "Alice", 92.5); pw.printf("%-5d %-15s %-6.1f%n", 2, "Bob", 78.0); pw.printf("%-5d %-15s %-6.1f%n", 3, "Charlie", 65.5); System.out.println("Report saved."); } catch (IOException e) { e.printStackTrace(); }

Checking if File Exists

File file = new File("output.txt"); if (file.exists()) { System.out.println("File found: " + file.getName()); System.out.println("Size: " + file.length() + " bytes"); } else { System.out.println("File does not exist."); }

Reading a File — BufferedReader

import java.io.*; public class ReadFile { public static void main(String[] args) { try (BufferedReader br = new BufferedReader( new FileReader("students.txt"))) { String line; while ((line = br.readLine()) != null) { System.out.println(line); } } catch (FileNotFoundException e) { System.out.println("File not found: " + e.getMessage()); } catch (IOException e) { System.out.println("Read error: " + e.getMessage()); } } }

Reading CSV Data into Objects

import java.io.*; import java.util.*; public class ReadCSV { public static void main(String[] args) { ArrayList records = new ArrayList<>(); try (BufferedReader br = new BufferedReader( new FileReader("students.txt"))) { String line = br.readLine(); while ((line = br.readLine()) != null) { String[] parts = line.split(","); records.add(parts); } } catch (IOException e) { e.printStackTrace(); } System.out.printf("%-5s %-15s %-5s %-6s%n", "ID", "Name", "Age", "Marks"); System.out.println("-".repeat(35)); for (String[] r : records) { System.out.printf("%-5s %-15s %-5s %-6s%n", r[0], r[1], r[2], r[3]); } } }

File Class — File Information

import java.io.*; File file = new File("students.txt"); System.out.println("Name: " + file.getName()); System.out.println("Path: " + file.getAbsolutePath()); System.out.println("Exists: " + file.exists()); System.out.println("Size: " + file.length() + " bytes"); System.out.println("Readable: " + file.canRead()); System.out.println("Writable: " + file.canWrite());

The File class represents a path and lets you inspect properties without opening the file. It can tell you the file’s name, absolute path, size, and whether it is readable or writable. This is useful for validating user input before you attempt actual I/O. File does not read the contents, so it is fast and safe to call. Use these checks to avoid exceptions and to show helpful messages.

Creating and Deleting Files

File file = new File("temp.txt"); if (file.createNewFile()) { System.out.println("File created."); } else { System.out.println("File already exists."); } if (file.delete()) { System.out.println("File deleted."); }

createNewFile() creates an empty file only if it does not already exist. This allows you to avoid overwriting existing data unintentionally. delete() removes the file, so you should confirm the return value to know if it succeeded. On some systems, deletion can fail if the file is open or permissions are missing. Always handle these cases to prevent silent errors.

Working with Directories

File dir = new File("reports"); dir.mkdir(); dir.mkdirs(); File folder = new File("."); String[] files = folder.list(); if (files != null) { for (String f : files) { System.out.println(f); } }

Directories are handled by the same File class and are created with mkdir or mkdirs. mkdir creates a single directory, while mkdirs creates any missing parent folders. Listing a directory with list() gives you the file names, which you can loop through. If list() returns null, the path may not exist or may not be a directory. This is a common starting point for building file explorers or batch processors.

Reading Entire File at Once (Java 11+)

import java.nio.file.*; String content = Files.readString(Path.of("output.txt")); System.out.println(content); String data = "Line 1\nLine 2\nLine 3"; Files.writeString(Path.of("quick.txt"), data);

Files.readString and Files.writeString provide a concise way to read or write an entire file in one call. They are perfect for small files like configuration or template files. Because they load the whole file into memory, they are not suitable for very large files. Using Path.of keeps paths clear and avoids manual stream handling. Always wrap these calls in try-catch to handle IOExceptions.

Full Example: Student File Manager

import java.io.*; import java.util.*; public class StudentFileManager { private static final String FILE = "students.csv"; public static void saveAll(ArrayList students) { try (BufferedWriter bw = new BufferedWriter( new FileWriter(FILE))) { bw.write("id,name,age,marks"); bw.newLine(); for (String[] s : students) { bw.write(String.join(",", s)); bw.newLine(); } System.out.println("Saved " + students.size() + " records."); } catch (IOException e) { System.out.println("Save error: " + e.getMessage()); } } public static ArrayList loadAll() { ArrayList list = new ArrayList<>(); File f = new File(FILE); if (!f.exists()) return list; try (BufferedReader br = new BufferedReader( new FileReader(FILE))) { br.readLine(); String line; while ((line = br.readLine()) != null) { if (!line.trim().isEmpty()) list.add(line.split(",")); } } catch (IOException e) { System.out.println("Load error: " + e.getMessage()); } return list; } public static void printAll(ArrayList students) { System.out.printf("%-5s %-15s %-5s %-6s%n", "ID", "Name", "Age", "Marks"); System.out.println("-".repeat(35)); for (String[] s : students) { System.out.printf("%-5s %-15s %-5s %-6s%n", s[0], s[1], s[2], s[3]); } } public static void main(String[] args) { ArrayList students = new ArrayList<>(); students.add(new String[]{"1", "Alice", "20", "92.5"}); students.add(new String[]{"2", "Bob", "22", "78.0"}); students.add(new String[]{"3", "Charlie", "21", "65.5"}); saveAll(students); ArrayList loaded = loadAll(); printAll(loaded); } }

This full example combines writing, reading, and printing so you can see a complete workflow. It writes a CSV header, saves each student row, and then reloads the data from disk. The loadAll method checks for missing files to avoid errors on the first run. The printAll method formats output so you can verify the data easily. This structure is a good template for many small data storage tasks.

Copying a File

import java.io.*; public class CopyFile { public static void copy(String source, String dest) { try (BufferedReader br = new BufferedReader(new FileReader(source)); BufferedWriter bw = new BufferedWriter(new FileWriter(dest))) { String line; while ((line = br.readLine()) != null) { bw.write(line); bw.newLine(); } System.out.println("Copied to: " + dest); } catch (IOException e) { System.out.println("Copy error: " + e.getMessage()); } } public static void main(String[] args) { copy("students.csv", "students_backup.csv"); } }

Copying a file line by line is a safe way to duplicate text files. The code reads each line from the source and writes it to the destination, preserving order. BufferedReader and BufferedWriter keep the operation fast for larger files. If the destination file already exists, it will be overwritten unless you open it in append mode. Always handle IOExceptions so you can report which file failed.

Common Mistakes

FileWriter fw = new FileWriter("file.txt"); fw.write("data"); catch (IOException e) { } catch (FileNotFoundException e) { System.out.println("File missing."); } bw.write("line\n"); bw.write("line"); bw.newLine(); String line = br.readLine(); System.out.println(line.length()); while ((line = br.readLine()) != null) { }

Common mistakes usually happen when resources are not closed or when errors are swallowed. An empty catch block hides real problems and makes debugging very hard. Using \n instead of newLine can produce files that look wrong on different operating systems. Reading a line without checking for null leads to NullPointerException at end of file. The list below highlights the fixes you should practice.

Mistake Why it breaks Correct Fix
Forgot close() Data stays in buffer, file empty Use try-with-resources
Catching IOException only Misses "File Not Found" specifics Catch FileNotFoundException too
Using \n Fails on some OS (Notepad) Use bw.newLine()
No null check Crash at end of file Check line != null

Practice Exercises

These exercises are designed to reinforce each file handling concept step by step. Focus on one task at a time and verify the output by opening the file. When you make a mistake, read the exception message and adjust your code. Try using both absolute and relative paths to understand how Java resolves file locations. Completing these tasks will make file I/O feel routine instead of risky.

  • Save your name, age, and city to profile.txt — practice basic writing.
  • Write 5 student records to students.txt using BufferedWriter — practice buffered output.
  • Append 3 more lines to an existing file using FileWriter append mode — practice safe appending.
  • Use PrintWriter to write a formatted table of 4 products — practice formatting.
  • Check if a file exists before writing and print its size — practice file metadata.
  • Read and print 5 names using BufferedReader — practice line-by-line reading.
  • Read CSV into Student objects and print them — practice parsing and display.
  • Create output directory and write 3 files inside it — practice directory operations.
  • Use Files.readString() and print character count — practice full-file reads.
  • Build a CSV save/load system for Product list — practice full workflow.
  • Copy a file using BufferedReader and BufferedWriter — practice file copying.
  • Count total words, lines, and characters in a text file — practice text analysis.
  • Find highest and lowest scorer from CSV — practice aggregation logic.
  • Append a log entry with timestamp to log.txt each run — practice logging.
