Introduction to Java

Java is a high-level, object-oriented programming language used to build software applications, web systems, mobile apps, enterprise tools, and large banking systems. It lets humans write instructions in a readable format that the computer can translate and execute.

Computers do not understand English or human reasoning. They understand only binary instructions (0s and 1s). Writing programs directly in binary would be nearly impossible for humans. Programming languages like Java act as a bridge between human thinking and machine execution.

Java was developed in 1995 by James Gosling and his team at Sun Microsystems. The goal was to create software that could run on different devices without rewriting the code for each device.

At that time, most programs were written specifically for one operating system. If you wrote software for Windows, it would not run on Linux or Mac without modification. This created maintenance problems and increased cost.

Write Once, Run Anywhere (WORA)

Why Java Became Popular

  • Platform dependency solved: Java avoids OS-specific compilation by using the JVM as a middle layer.
  • Safety and reliability: Java prevents common issues like memory corruption, pointer misuse, and buffer overflow.
  • Structured programming: Java enforces rules such as writing code inside classes, which improves maintainability.
Program → JVM → Windows / Linux / Mac

Important Java Components

JDK (Java Development Kit)

The JDK is the complete package used by programmers to develop Java applications. It includes the compiler (javac), the JVM, standard libraries, and debugging tools.

Think of JDK as a full workshop with tools required to build software.

JRE (Java Runtime Environment)

The JRE is used only to run Java programs. It contains the JVM and core libraries required for execution, but it does not include the compiler.

Think of JRE as the engine required to operate a machine built by developers.

JVM (Java Virtual Machine)

The JVM acts as a virtual computer inside your real computer. Java programs do not run directly on the operating system. Instead, bytecode runs inside the JVM, which converts it to machine code.

Java program → Bytecode → JVM → Machine code → Output
Exam Point: The JVM is the true reason Java is platform-independent.

How a Java Program Runs

  1. Write the program: Hello.java
  2. Compile the program using the compiler:
javac Hello.java

The compiler checks syntax and creates bytecode: Hello.class

  1. Run the program using the JVM:
java Hello

Program Structure

Every Java program must follow a strict format. Instructions cannot exist outside a class.

public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }

The file name must match the class name exactly: Hello.java → class Hello

Understanding Each Part

  • public class Hello declares a class named Hello.
  • main() is the starting point of the program.
  • System.out.println prints output on the screen.
  • Every statement ends with a semicolon.

main() method

This is the starting point of every Java program. When the program runs, the JVM searches for this method first.

public static void main(String[] args)
  • public → accessible everywhere
  • static → runs without creating an object
  • void → returns no value
  • main → program entry point
  • String[] args → accepts command line inputs
Exam Point: Without main(), Java cannot start execution.

Print Statements

To display output, Java uses:

System.out.println("Hello World");

System = system resources, out = output stream, println = print line.

System.out.println("Welcome"); System.out.println(2025); System.out.println("Age: " + 20);

Text requires quotes, numbers do not.

Comments

Comments are ignored by the compiler and help programmers understand code.

// this is a comment /* multiple line comment */
  • Single-line comments start with //
  • Multi-line comments use /* and */

Compilation & Execution

Java programs execute in two stages: compilation and execution.

javac Hello.java java Hello
  • The compiler checks errors such as missing semicolon or missing quotes.
  • If errors exist, the program will not run.
  • The JVM loads bytecode and executes instructions.

Summary

  • Java was created by James Gosling to solve portability problems.
  • JVM enables platform independence using bytecode.
  • Programs are written inside classes and start from main().
  • Compilation checks correctness, execution produces output.
