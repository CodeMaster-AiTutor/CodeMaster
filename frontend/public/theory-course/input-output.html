Input Output

Scanner class

The Scanner class reads input from the keyboard. It is in the java.util package, so you must import it.

Scanner breaks input into tokens, which are pieces of data separated by spaces or new lines.

You usually create one Scanner object and reuse it for the entire program.

import java.util.Scanner; Scanner sc = new Scanner(System.in);
Exam Point: Write the import statement for Scanner.

Taking integer input

Use nextInt() to read an integer.

This method expects a valid whole number, so typing text will cause an input error.

After reading, the value is stored in an int variable for later use.

int age; age = sc.nextInt(); System.out.println("Age: " + age);
Exam Point: Which Scanner method reads an int?

Taking string input

Use next() for a single word and nextLine() for a full line including spaces.

next() stops reading at the first space, so it cannot capture full names with spaces.

nextLine() reads the entire line, which is useful for full names or sentences.

String name = sc.next(); String city = sc.nextLine();
Exam Point: Difference between next() and nextLine().

Multiple inputs

You can read multiple values in sequence. Inputs are read in the order typed.

Each method consumes only the part of input it needs, so order matters.

Mixing nextInt and nextLine requires care because nextInt leaves a newline behind.

int roll = sc.nextInt(); String name = sc.next(); double marks = sc.nextDouble();
Exam Point: What happens if input order is wrong?

Formatting output

Use printf for formatted output. It allows control over decimals and alignment.

Format specifiers like %d, %f, and %s tell Java what type of value to print.

%.2f means show two digits after the decimal point.

System.out.printf("Marks: %.2f", 89.456); System.out.printf("\nName: %s", "Riya");
Exam Point: Explain the role of %.2f.
