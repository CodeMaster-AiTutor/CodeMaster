Strings

String basics & immutability

A String is a sequence of characters inside double quotes. Strings are immutable—once created, their content cannot change. Any “change” creates a new String.

String s1 = "Java"; // literal in String Pool String s2 = new String("Java"); // new object on heap s1 = s1 + " Rocks"; // creates a new String
Exam Point: Why is immutability useful? (thread-safety, caching, security)

equals() vs ==

equals() compares content; == compares references.

String a = "Hello"; String b = "Hello"; // may refer to same pool object String c = new String("Hello"); System.out.println(a.equals(c)); // true System.out.println(a == c); // false
Exam Point: Always use equals() for content comparison.

Essential methods

String s = " Programming "; int n = s.length(); // 13 char ch = s.charAt(1); // 'r' int p = s.indexOf("gram"); // 4 int lp = s.lastIndexOf("g"); // 10 String sub = s.substring(1, 5); // "rogr" String up = s.toUpperCase(); // " PROGRAMMING " String low = s.toLowerCase(); String t = s.trim(); // removes ends spaces String rep = s.replace("m", "MM"); boolean st = s.startsWith(" "); boolean en = s.endsWith(" "); boolean has = s.contains("Pro");

Comparison

String x = "Apple", y = "banana"; int cmp = x.compareTo(y); // dictionary order boolean eqi = x.equalsIgnoreCase("apple");
Exam Point: compareTo returns 0 if contents are equal.

Split & Join

String data = "red,green,blue"; String[] parts = data.split(","); String back = String.join("-", parts); // "red-green-blue"

StringBuilder (for performance)

Use StringBuilder when building strings in loops to avoid creating many temporary objects.

StringBuilder sb = new StringBuilder(); for (int i = 1; i <= 3; i++) { sb.append(i).append(", "); } String res = sb.toString();
Exam Point: StringBuilder is mutable; String is immutable.
