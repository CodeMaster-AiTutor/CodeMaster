Arrays

What Problem Arrays Solve

Real programs store groups of related values: marks of 100 students, daily temperatures, cart prices, scores in a leaderboard. Using separate variables makes code unmanageable, prevents looping, and does not scale. We need one variable that can hold many values: an array.

Definition of Array

An array is a fixed-size collection of elements of the same data type stored in contiguous memory.

  • Fixed size: decided at creation, cannot change later.
  • Same type: int[] stores only ints; no mixing types.
  • Contiguous memory: elements are side-by-side, enabling fast access.
Exam Point: Give the three key properties of an array.

Memory concept

int a = 10; // one memory box int[] arr = new int[5]; // 5 connected boxes

Each position is reached by an index. Indexing starts from 0.

Index system

  • Size = 5 → valid indexes: 0,1,2,3,4
  • 1st element index = 0; last index = size − 1
  • Reason: CPU calculates address as base + index × elementSize

Declaring an array

Declaration creates a reference, not the actual array.

double[] prices; char[] grades; String[] names;

Creating an array

Allocate memory using new:

int[] marks = new int[5]; // space for 5 ints int[] quick = {78, 85, 90, 66, 72}; // direct initialization

Default values

Elements are initialized automatically:

  • int → 0, double/float → 0.0, boolean → false
  • char → '\u0000' (empty), object refs (e.g., String) → null
int[] a = new int[3]; System.out.println(a[0]); // 0

Assigning & accessing

int[] marks = new int[5]; marks[0] = 78; marks[1] = 85; marks[2] = 90; marks[3] = 66; marks[4] = 72; System.out.println(marks[2]); // 90

Array length property

Use length (property, not a method).

System.out.println(marks.length); // correct // marks.length() // incorrect

Traversing an array

int[] arr2 = {2, 4, 6, 8}; for (int i = 0; i < arr2.length; i++) { System.out.println(arr2[i]); } // Enhanced for-each (no index needed) for (int value : arr2) { System.out.println(value); }

Searching (linear search)

Check elements one by one until found. Time complexity: O(n).

int key = 90; boolean found = false; for (int i = 0; i < marks.length; i++) { if (marks[i] == key) { found = true; break; } }

Finding maximum & minimum

int[] a3 = {4, 7, 1, 9}; int min = a3[0], max = a3[0]; for (int i = 1; i < a3.length; i++) { if (a3[i] < min) min = a3[i]; if (a3[i] > max) max = a3[i]; } System.out.println(min + " " + max);

Array Index Out of Bounds

Accessing outside 0..length-1 throws ArrayIndexOutOfBoundsException to protect memory.

int[] b = new int[3]; // b[3] = 100; // invalid; valid indexes are 0..2

Why arrays are fast

Contiguous memory enables constant-time access.

address = base + (index * sizeOfType) // Access time = O(1)

Limitations

  • Size fixed after creation
  • No mixed types
  • Insertion/deletion in middle is costly
  • Wasted memory if size is overestimated

When to use arrays

  • Number of elements known beforehand
  • Frequent reading and indexed access
  • Performance critical and memory predictable
  • Examples: marks list, days of week, seat numbers

Practice Tasks

Solve these to strengthen array fundamentals.

1) Reverse an array in-place

int[] a = {1, 2, 3, 4, 5}; int i = 0, j = a.length - 1; while (i < j) { int temp = a[i]; a[i] = a[j]; a[j] = temp; i++; j--; }

2) Count frequency of a value

int[] marks = {78, 85, 90, 78, 66, 78}; int key = 78, freq = 0; for (int x : marks) { if (x == key) freq++; } System.out.println(freq);

3) Find second largest (distinct)

int[] a2 = {5, 9, 2, 9, 4}; int max1 = Integer.MIN_VALUE, max2 = Integer.MIN_VALUE; for (int v : a2) { if (v > max1) { max2 = max1; max1 = v; } else if (v > max2 && v != max1) { max2 = v; } } System.out.println(max2);
