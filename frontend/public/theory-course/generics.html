Generics

What are Generics?

Generics let you write classes, interfaces, and methods that work with any type, while the compiler checks type correctness at compile time.

This means you can reuse the same code for different data types without losing type safety.

Generics reduce casting and runtime errors by moving type checks to compile time.

ArrayList names = new ArrayList<>(); HashMap scores = new HashMap<>();

The Problem Generics Solve

Before Java 5, developers used Object for any type, which allowed unsafe casts and runtime crashes.

The compiler could not stop you from putting the wrong type into a container.

Generics fix this by locking the type at compile time.

public class Box { private Object value; public void set(Object value) { this.value = value; } public Object get() { return value; } } Box box = new Box(); box.set("Hello"); String s = (String) box.get(); Integer n = (Integer) box.get();

With generics, the compiler blocks wrong types.

public class Box { private T value; public void set(T value) { this.value = value; } public T get() { return value; } } Box box2 = new Box<>(); box2.set("Hello"); String s2 = box2.get();

Type Parameter Conventions

Single-letter type names are a convention that makes generic code short and readable.

Use meaningful letters that indicate purpose (key, value, element).

T → Type (general) E → Element (collections) K → Key (maps) V → Value (maps)

Generic Classes

A generic class defines one or more type parameters that are fixed when you create an object.

This ensures every field and method in that object uses the same type consistently.

public class Box { private T value; public Box(T value) { this.value = value; } public void set(T value) { this.value = value; } public T get() { return value; } @Override public String toString() { return "Box[" + value + "]"; } }
Box strBox = new Box<>("Hello"); Box intBox = new Box<>(42); Box dblBox = new Box<>(3.14); System.out.println(strBox.get()); System.out.println(intBox.get()); System.out.println(dblBox.get());

Two Type Parameters

Multiple type parameters let you model pairs, entries, or mappings with different types.

This pattern is common in maps and key-value structures.

public class Pair { private K key; private V value; public Pair(K key, V value) { this.key = key; this.value = value; } public K getKey() { return key; } public V getValue() { return value; } @Override public String toString() { return "(" + key + ", " + value + ")"; } }
Pair student = new Pair<>("Alice", 92); System.out.println(student); Pair capital = new Pair<>("India", "New Delhi"); System.out.println(capital);

Diamond Operator and Primitives

The diamond operator <> lets the compiler infer type parameters to reduce repetition.

Generics do not work with primitives, so use wrapper types like Integer, Double, and Boolean.

Box box3 = new Box<>("Hello"); Box box4 = new Box<>(5); int val = box4.get();
Exam Point: Generics work with wrapper classes, not primitives.

Generic Methods

A generic method declares its own type parameters, even inside a non-generic class.

This is useful for utility logic like printing, swapping, or searching arrays of any type.

public class Utils { public static void printArray(T[] array) { System.out.print("["); for (int i = 0; i < array.length; i++) { System.out.print(array[i]); if (i < array.length - 1) System.out.print(", "); } System.out.println("]"); } public static T getFirst(T[] array) { return (array == null || array.length == 0) ? null : array[0]; } public static void swap(T[] arr, int i, int j) { T temp = arr[i]; arr[i] = arr[j]; arr[j] = temp; } } Integer[] nums = {1, 2, 3, 4, 5}; String[] names2 = {"Alice", "Bob", "Charlie"}; Utils.printArray(nums); Utils.printArray(names2); System.out.println(Utils.getFirst(names2)); Utils.swap(nums, 0, 4); Utils.printArray(nums);

Bounded Type Parameters

Bounds restrict which types are allowed, so you can safely call methods on the type.

For example, extends Number guarantees numeric methods like doubleValue().

public static double sum(T a, T b) { return a.doubleValue() + b.doubleValue(); } public static > T findMax(T[] arr) { T max = arr[0]; for (T item : arr) if (item.compareTo(max) > 0) max = item; return max; } System.out.println(sum(5, 10)); System.out.println(sum(3.5, 2.5)); Integer[] nums2 = {3, 7, 1, 9}; String[] words = {"Charlie", "Alice", "Bob"}; System.out.println(findMax(nums2)); System.out.println(findMax(words));

Multiple Bounds

public static > T clamp(T val, T min, T max) { if (val.compareTo(min) < 0) return min; if (val.compareTo(max) > 0) return max; return val; } System.out.println(clamp(5, 1, 10)); System.out.println(clamp(-3, 1, 10)); System.out.println(clamp(15, 1, 10));

Wildcards

Wildcards allow flexibility when you do not know the exact type parameter.

? extends T is a producer, ? super T is a consumer, and ? is unknown.

public static double sumList(ArrayList list) { double total = 0; for (Number n : list) total += n.doubleValue(); return total; } ArrayList ints = new ArrayList<>(Arrays.asList(1, 2, 3)); ArrayList dbls = new ArrayList<>(Arrays.asList(1.5, 2.5)); System.out.println(sumList(ints)); System.out.println(sumList(dbls));
public static void fillNumbers(ArrayList list) { list.add(10); list.add(20); list.add(30); } public static void printList(ArrayList list) { for (Object item : list) System.out.print(item + " "); System.out.println(); }
PECS → Producer Extends, Consumer Super → reading only → reading → writing

Generic Interfaces

public interface Repository { void save(T item); T findById(ID id); void delete(ID id); int count(); }
public class StudentRepository implements Repository { private HashMap store = new HashMap<>(); private int nextId = 1; @Override public void save(Student s) { store.put(nextId++, s); System.out.println("Saved: " + s.getName()); } @Override public Student findById(Integer id) { return store.getOrDefault(id, null); } @Override public void delete(Integer id) { store.remove(id); System.out.println("Deleted id: " + id); } @Override public int count() { return store.size(); } }
StudentRepository repo = new StudentRepository(); repo.save(new Student("Alice", 20)); repo.save(new Student("Bob", 22)); System.out.println("Total: " + repo.count()); System.out.println(repo.findById(1)); repo.delete(1); System.out.println("Total: " + repo.count());
