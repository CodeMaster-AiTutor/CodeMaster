JDBC

What is JDBC?

JDBC (Java Database Connectivity) is Java’s standard API for connecting to relational databases and running SQL.

It provides a consistent way to work with databases using Java code, regardless of the database vendor.

JDBC bridges Java programs with SQL databases through drivers.

  • Connect to a database (MySQL, PostgreSQL, SQLite)
  • Run SQL queries (SELECT, INSERT, UPDATE, DELETE)
  • Read results into Java objects
  • Handle transactions safely

How JDBC Works

The JDBC API is implemented by database drivers. Your code talks to JDBC, and the driver talks to the database.

This separation lets you switch databases with minimal code changes.

Java Program → JDBC API → JDBC Driver → Database
  • JDBC API: Connection, Statement, ResultSet
  • JDBC Driver: database-specific implementation
  • Swap driver to switch databases without changing app logic

Setup — Add MySQL Driver

Every database needs a driver. Add the driver dependency to your project so JDBC can communicate with the database.

Other databases (PostgreSQL, Oracle, SQLite) require their own driver dependencies.

mysql mysql-connector-java 8.0.33
CREATE DATABASE school; USE school; CREATE TABLE students ( id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(100), age INT, grade CHAR(1) ); INSERT INTO students (name, age, grade) VALUES ('Alice', 20, 'A'), ('Bob', 22, 'B'), ('Charlie', 21, 'A'), ('Diana', 19, 'C');

Step 1 — Establishing a Connection

A Connection represents an active session with the database. It is expensive to create, so reuse or pool in real applications.

The URL encodes host, port, and database name.

import java.sql.Connection; import java.sql.DriverManager; import java.sql.SQLException; public class DBConnection { public static void main(String[] args) { String url = "jdbc:mysql://localhost:3306/school"; String username = "root"; String password = "yourpassword"; try { Connection conn = DriverManager.getConnection(url, username, password); System.out.println("Connected successfully!"); conn.close(); } catch (SQLException e) { System.out.println("Connection failed: " + e.getMessage()); } } }
jdbc:mysql://host:port/databasename jdbc:mysql://localhost:3306/school

Step 2 — Executing a SELECT Query

SELECT queries return a ResultSet. Use Statement for simple queries or PreparedStatement for safer parameterized queries.

import java.sql.*; public class SelectExample { public static void main(String[] args) { String url = "jdbc:mysql://localhost:3306/school"; String user = "root"; String pass = "yourpassword"; try { Connection conn = DriverManager.getConnection(url, user, pass); Statement stmt = conn.createStatement(); ResultSet rs = stmt.executeQuery("SELECT * FROM students"); System.out.printf("%-5s %-15s %-5s %-6s%n", "ID", "Name", "Age", "Grade"); System.out.println("-".repeat(35)); while (rs.next()) { int id = rs.getInt("id"); String name = rs.getString("name"); int age = rs.getInt("age"); String grade = rs.getString("grade"); System.out.printf("%-5d %-15s %-5d %-6s%n", id, name, age, grade); } rs.close(); stmt.close(); conn.close(); } catch (SQLException e) { e.printStackTrace(); } } }

ResultSet Methods

ResultSet is a cursor over rows. Use next() to move row by row, then read columns by name or index.

Column names are clearer, but indexes can be slightly faster for large loops.

rs.getInt("column") rs.getString("column") rs.getDouble("column") rs.getBoolean("column") rs.next()
int id = rs.getInt(1); String name = rs.getString(2);

Always Close Resources

Not closing connections wastes resources and can crash your app over time.

Use try‑with‑resources to close Connection, Statement, and ResultSet automatically.

try ( Connection conn = DriverManager.getConnection(url, user, pass); Statement stmt = conn.createStatement(); ResultSet rs = stmt.executeQuery("SELECT * FROM students") ) { while (rs.next()) { System.out.println(rs.getString("name")); } } catch (SQLException e) { e.printStackTrace(); }

executeUpdate() — INSERT, UPDATE, DELETE

Use executeQuery() for SELECT, and executeUpdate() for INSERT/UPDATE/DELETE.

executeUpdate returns the number of rows affected, which is useful for verifying changes.

String sql = "INSERT INTO students (name, age, grade) VALUES ('Eve', 20, 'B')"; int rowsAffected = stmt.executeUpdate(sql);
String sql = "UPDATE students SET grade = 'A' WHERE name = 'Bob'"; int rows = stmt.executeUpdate(sql);
String sql = "DELETE FROM students WHERE id = 4"; int rows = stmt.executeUpdate(sql);

The Problem with Statement — SQL Injection

String concatenation allows attackers to inject SQL. This can expose or modify data.

Always use parameterized queries to prevent injection.

String name = "Alice' OR '1'='1"; String sql = "SELECT * FROM students WHERE name = '" + name + "'";

PreparedStatement — Safe and Better

PreparedStatement precompiles SQL with placeholders and safely binds parameters.

It improves security and can improve performance for repeated queries.

String sql = "SELECT * FROM students WHERE grade = ?"; try (Connection conn = DriverManager.getConnection(url, user, pass); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setString(1, "A"); ResultSet rs = ps.executeQuery(); while (rs.next()) { System.out.println(rs.getString("name") + " — " + rs.getString("grade")); } } catch (SQLException e) { e.printStackTrace(); }
String sql = "INSERT INTO students (name, age, grade) VALUES (?, ?, ?)"; try (Connection conn = DriverManager.getConnection(url, user, pass); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setString(1, "Frank"); ps.setInt(2, 23); ps.setString(3, "B"); int rows = ps.executeUpdate(); System.out.println("Inserted: " + rows + " row(s)"); } catch (SQLException e) { e.printStackTrace(); }
String sql = "UPDATE students SET age = ? WHERE name = ?"; try (Connection conn = DriverManager.getConnection(url, user, pass); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setInt(1, 25); ps.setString(2, "Alice"); int rows = ps.executeUpdate(); System.out.println("Updated: " + rows + " row(s)"); }

PreparedStatement Setter Methods

Setters bind Java values into SQL placeholders in order. Index starts at 1.

Use setNull when a column should be stored as NULL.

ps.setInt(index, value) ps.setString(index, value) ps.setDouble(index, value) ps.setBoolean(index, value) ps.setNull(index, Types.VARCHAR)

Index starts at 1, not 0.

Batch Inserts — Multiple Rows at Once

Batching reduces network round‑trips by sending multiple statements together.

It is faster for inserting large datasets.

String sql = "INSERT INTO students (name, age, grade) VALUES (?, ?, ?)"; try (Connection conn = DriverManager.getConnection(url, user, pass); PreparedStatement ps = conn.prepareStatement(sql)) { String[][] data = { {"Grace", "21", "A"}, {"Henry", "22", "B"}, {"Iris", "20", "A"} }; for (String[] row : data) { ps.setString(1, row[0]); ps.setInt(2, Integer.parseInt(row[1])); ps.setString(3, row[2]); ps.addBatch(); } int[] results = ps.executeBatch(); System.out.println("Batch inserted: " + results.length + " rows"); } catch (SQLException e) { e.printStackTrace(); }

Transactions

A transaction groups multiple statements into one unit. Either all succeed or all are rolled back.

Use transactions for money transfers or multi‑step updates that must stay consistent.

Connection conn = null; try { conn = DriverManager.getConnection(url, user, pass); conn.setAutoCommit(false); PreparedStatement debit = conn.prepareStatement( "UPDATE accounts SET balance = balance - ? WHERE id = ?"); debit.setDouble(1, 500); debit.setInt(2, 1); debit.executeUpdate(); PreparedStatement credit = conn.prepareStatement( "UPDATE accounts SET balance = balance + ? WHERE id = ?"); credit.setDouble(1, 500); credit.setInt(2, 2); credit.executeUpdate(); conn.commit(); System.out.println("Transfer successful!"); } catch (SQLException e) { if (conn != null) { conn.rollback(); System.out.println("Transfer failed. Rolled back."); } e.printStackTrace(); } finally { if (conn != null) conn.close(); }
conn.setAutoCommit(false) conn.commit() conn.rollback()

DB Utility Class

A utility class centralizes connection creation and cleanup logic.

This keeps JDBC code cleaner and avoids duplication.

import java.sql.*; public class DBUtil { private static final String URL = "jdbc:mysql://localhost:3306/school"; private static final String USER = "root"; private static final String PASS = "yourpassword"; public static Connection getConnection() throws SQLException { return DriverManager.getConnection(URL, USER, PASS); } public static void close(Connection conn, PreparedStatement ps, ResultSet rs) { try { if (rs != null) rs.close(); if (ps != null) ps.close(); if (conn != null) conn.close(); } catch (SQLException e) { e.printStackTrace(); } } }

Full CRUD Example: Student Manager

This example shows how to create, read, update, and delete records using PreparedStatement.

It demonstrates a basic DAO pattern often used in real applications.

import java.sql.*; public class StudentDAO { public static void addStudent(String name, int age, String grade) throws SQLException { String sql = "INSERT INTO students (name, age, grade) VALUES (?, ?, ?)"; try (Connection conn = DBUtil.getConnection(); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setString(1, name); ps.setInt(2, age); ps.setString(3, grade); ps.executeUpdate(); System.out.println("Added: " + name); } } public static void getAllStudents() throws SQLException { String sql = "SELECT * FROM students ORDER BY id"; try (Connection conn = DBUtil.getConnection(); PreparedStatement ps = conn.prepareStatement(sql); ResultSet rs = ps.executeQuery()) { System.out.printf("%-5s %-15s %-5s %-6s%n", "ID", "Name", "Age", "Grade"); System.out.println("-".repeat(35)); while (rs.next()) { System.out.printf("%-5d %-15s %-5d %-6s%n", rs.getInt("id"), rs.getString("name"), rs.getInt("age"), rs.getString("grade")); } } } public static void updateGrade(int id, String grade) throws SQLException { String sql = "UPDATE students SET grade = ? WHERE id = ?"; try (Connection conn = DBUtil.getConnection(); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setString(1, grade); ps.setInt(2, id); int rows = ps.executeUpdate(); System.out.println(rows > 0 ? "Updated!" : "Student not found."); } } public static void deleteStudent(int id) throws SQLException { String sql = "DELETE FROM students WHERE id = ?"; try (Connection conn = DBUtil.getConnection(); PreparedStatement ps = conn.prepareStatement(sql)) { ps.setInt(1, id); int rows = ps.executeUpdate(); System.out.println(rows > 0 ? "Deleted!" : "Student not found."); } } public static void main(String[] args) throws SQLException { addStudent("Zara", 21, "A"); addStudent("Sam", 23, "B"); getAllStudents(); updateGrade(1, "A+"); deleteStudent(2); System.out.println("\nAfter changes:"); getAllStudents(); } }

Common Mistakes

Common errors include leaking connections, building SQL with string concatenation, and skipping transactions.

Connection conn = DriverManager.getConnection(...); // forgot conn.close() stmt.executeQuery("SELECT * WHERE name = '" + input + "'"); // use PreparedStatement instead stmt.executeUpdate("UPDATE accounts ..."); stmt.executeUpdate("UPDATE accounts ..."); // should be in a transaction
